# 과학 1 단원평가 기록보관소 (웹앱 v1.1.0)

중학교 1학년 과학 7개 단원의 단원평가 앱입니다. 단원마다 A형(개념 확인), B형(자료 해석), C형(생활 적용) 세 유형이 있고, 유형마다 20문항(선택형 15, 서술형 5)입니다. 한 번 열어 두면 인터넷이 끊겨도 시험을 볼 수 있습니다.

## v1.1.0에서 달라진 점

- **자동 전송:** 학생이 제출하면 점수가 선생님의 Google 스프레드시트로 자동 전송됩니다.
- **오프라인 제출:** 인터넷이 끊긴 상태에서 제출한 점수는 기기에 보관해 두었다가, 연결되면 자동으로 보냅니다.
- **저장 상태 표시:** 결과지와 응시 기록 화면에 "선생님 점수표에 저장됨"처럼 저장 상태가 보입니다.
- **파일로 내보내기:** 응시 기록 화면에서 점수를 엑셀용 CSV 파일로 저장할 수 있습니다. "내 점수"와 "이 기기 전체 점수" 두 가지로 저장됩니다.

## 폴더 구성

```
webapp/            GitHub Pages에 올리는 폴더 (이 안의 파일만 올립니다)
  config.js        선생님 설정 파일: 점수표 주소와 비밀 문구
  index.html       앱 본체 (문항 420개)
  sw.js            오프라인 저장(서비스 워커)
  manifest.webmanifest, fonts/, icons/, .nojekyll
apps-script/
  Code.gs          점수를 받아 스프레드시트에 적는 코드 (GitHub에는 올리지 않습니다)
```

## 1단계, 점수표 만들기 (처음 한 번)

1. Google 드라이브에서 새 스프레드시트를 만듭니다. 예: "2026 과학1 단원평가 점수"
2. 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 모두 붙여 넣은 뒤 저장합니다.
4. 코드 맨 위 `TOKEN`의 비밀 문구를 원하는 값으로 바꿉니다. 예: `"dure-science-2026"`
5. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 "웹 앱"을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 권한 승인 창이 나오면 계정을 고르고 허용합니다. "확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누릅니다. 본인이 만든 코드라 괜찮습니다.
7. `https://script.google.com/macros/s/…/exec` 주소가 나오면 복사해 둡니다.
8. 복사한 주소를 브라우저에 붙여 열었을 때 "점수 수집기가 작동 중입니다."가 보이면 준비가 끝난 것입니다.

## 2단계, 앱에 점수표 연결하기

`webapp/config.js`를 메모장으로 열어 두 줄을 채웁니다.

```js
scoreUrl: "https://script.google.com/macros/s/…/exec",
token: "dure-science-2026"      // Code.gs의 TOKEN과 똑같이
```

`scoreUrl`을 비워 두면 점수는 학생 기기에만 저장되고, CSV 파일로 모을 수 있습니다.

## 3단계, GitHub Pages로 배포하기

1. GitHub에 새 저장소를 만듭니다. 예: `science1-exam`
2. `webapp` 폴더 **안의** 파일을 모두 저장소 맨 위에 올립니다. `.nojekyll`은 숨김 파일이라 안 보일 수 있으니 폴더째 끌어다 놓거나 GitHub Desktop을 쓰세요.
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/science1-exam/` 주소가 생깁니다. 이 주소를 학생에게 QR 코드로 나눠 주세요.

## 점수표 보는 법

- "점수" 시트에 제출 한 건이 한 줄씩 쌓입니다.
- 같은 제출이 두 번 전송돼도 한 줄만 남습니다.
- **교사 확인 총점(노란 칸):** 서술형 자동 채점을 고쳐야 할 때 이 칸에 최종 점수를 적으세요.
- **서술형 확인:** 16~20번 답안과 자동 점수가 함께 적혀 있어 서술형을 확인하기 쉽습니다.
- **정렬과 필터:** 스프레드시트의 필터 기능으로 단원, 유형, 반별로 모아 보면 됩니다.

## 학생 기기에 설치하기

- **크롬북, 윈도우, 안드로이드:** 크롬이나 엣지로 열면 화면 아래 "앱 설치" 버튼이 나옵니다.
- **아이폰, 아이패드:** 사파리에서 공유 → "홈 화면에 추가"를 누릅니다.

## 고친 뒤 다시 배포할 때

- **`config.js`만 고친 경우:** 파일만 다시 올리면 됩니다. 학생 기기가 인터넷에 연결될 때 새 설정을 읽습니다.
- **`index.html`(문항)을 고친 경우:** `sw.js` 첫 줄 버전을 꼭 올려 주세요. 예: `v1.1.0` → `v1.1.1`. 버전을 올리지 않으면 학생 기기에 이전 문항이 남습니다.
- **`Code.gs`를 고친 경우:** 배포 → 배포 관리 → 연필 아이콘 → 버전 "새 버전"으로 다시 배포해야 반영됩니다. 이렇게 하면 주소는 그대로입니다.

## 알아 두실 점

- **비밀 문구의 한계:** `config.js`는 누구나 볼 수 있는 파일이라 비밀 문구도 공개됩니다. 아무 사이트에서나 점수표에 글을 보내는 것을 막는 정도의 장치이니, 학생 명단 외의 이상한 줄이 보이면 지우시면 됩니다.
- **기기 저장 범위:** 학생 기기에는 최근 300건까지 기록이 남습니다. 브라우저 기록을 지우면 기기 기록은 사라지지만, 이미 점수표로 보낸 점수는 남습니다.
- **서술형 채점:** 핵심어 기준 자동 채점이므로 최종 점수는 선생님이 확인해 주세요.
